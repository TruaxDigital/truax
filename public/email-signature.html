Gmail signatures

Gmail does not accept pasted HTML code, so copy the rendered signature instead:

  1. Click and drag to select the whole signature below (from the photo to the last line).
  2. Copy it (Cmd+C or Ctrl+C).
  3. In Gmail: Settings, See all settings, General, Signature, Create new. Paste into the box.
  4. Save changes at the bottom of the page.
